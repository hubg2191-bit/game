# Thrones & Towns — 0.2 Экономика Townsmen

Web-RTS (Three.js + Vite). Playable по `docs/gdd/08-roadmap.md`:
1 раса (Нордвейн), карта «Равнина», 4 отряда, бот-пустышка, победа — 1000 очков или снос Ратуши.

0.2 добавляет: капы складов, голод, фланги x1.5/x2, лес-стелс, нейтралы (волки/бандиты) с наградами,
туман войны, мельницу/пекарню/рынок (обмен)/храм, ап Ратуши до ур.3, хоткеи и группы.

## Запуск

```powershell
cd three-game-vite
npm install
npm run dev
```

Открыть http://localhost:5173

## Управление

- ЛКМ — выбрать отряд/здание, рамкой — несколько, дабл-клик — всех таких на экране, Shift+клик — добавить
- ПКМ — идти / атаковать (атака + захват по пути), ПКМ по миникарте — быстрый марш
- `A` — режим атаковать-идти, `S` — стоп, `H` — к Ратуше, `Пробел` — к последнему бою
- `Ctrl+1..9` / `1..9` — группы, `Esc` — отмена
- Найм: выбрать Ратушу (Ополчение) или Казармы (Мечники, Копейщики, Лучники)
- Стройка: кнопки внизу → ЛКМ по земле. Лесопилка только у леса, шахта у холмов,
  мельница/рынок/храм требуют Ратушу-2, пекарня — Ратушу-3 + мельницу
- Ап Ратуши — кнопка в панели здания. Обмен дерева на золото — в панели Рынка
- Флаги захватываются отрядом 8+ бойцов. Волки/бандиты охраняют споты — за зачистку награда

## Структура

- `src/game/sim.js` — чистая симуляция (shared/sim по GDD 07-tech)

- `src/game/data/*.json` — баланс (единственное место правок цифр)
