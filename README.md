# Thrones & Towns — 1.0 Релиз

Web-RTS (Three.js + Vite). Playable по `docs/gdd/08-roadmap.md`.

1.0: кузница (гейт железной армии + 3 апа), 3-я карта Перевал (FFA, горы/проходы),
5 миссий обучения, кооп-пинги союзнику (Alt+клик, F1/F2/F4) + передача дерева,
таверна с дейликами, герои 1-30 + перки + крафт фиолета, APM-лимит 10/с, автосезоны.

## Запуск

```powershell
cd three-game-vite
npm install
npm run dev
```

Открыть http://localhost:5173

## Управление

- ЛКМ — выбрать отряд/здание, рамкой — несколько, дабл-клик — всех таких на экране, Shift+клик — добавить
- ПКМ — идти / атаковать (атака + захват по пути), ПКМ по миникарте — быстрый марш
- `A` — режим атаковать-идти, `S` — стоп, `F` — рассыпной строй (-50% от осадных),
  `H` — к Ратуше, `Пробел` — к последнему бою
- `Ctrl+1..9` / `1..9` — группы, `Esc` — отмена, камера — стрелки/WSD + колесо
- Найм: Ратуша (ополчение), Казармы (мечи/копья + гвардия/алебардисты с уникалкой),
  Стрельбище (луки/арбалеты), Конюшня (кава + нукеры с табуном),
  Осадная (баллиста/требушет, лимит 2), Храм (лекарь)
- Стройка: лесопилка у леса, шахта у холмов/рудников, в воде нельзя;
  мельница/рынок/храм/стрельбище — от Ратуши-2; конюшня/осада/уникалка — от Ратуши-3
- Стены (камень, от Ратуши-3, макс 30): держат всех, ворот нет — оставляйте проходы
- Флаги захватываются отрядом 8+ бойцов. Реплей — кнопка на экране победы

## Структура

- `src/game/sim.js` — чистая симуляция (shared/sim по GDD 07-tech)
- `src/game/render.js` — Three.js сцена (client/three)
- `src/game/ui.js` — HUD поверх canvas (client/ui)
- `src/game/data/*.json` — баланс (единственное место правок цифр)
- `docs/gdd/` — дизайн-документ
