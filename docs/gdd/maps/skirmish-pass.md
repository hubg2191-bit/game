# Арена Горный перевал — skirmish-pass

Назначение: FFA до 4, засады, высоты.

## Схема
- Крест-перевал: 4 базы по углам, центр-плато +8м (только 2 тропы по 6м).
- Флаги: Плато (руины +5% ко всему), 2 боковых холма (железо).
- Лес густой вдоль троп (засады Следопыта). Горы непроходимы.
- Камня много, дерева мало — стены решают.

## Тактика
- Плато держит 1 каре гвардии + арбалеты сверху — не выбить в лоб. Только метка + требушеты или обход.
- FFA:fts дипломатия пинами `бей красного`, временные союзы до 2 мин (кнопка).
- Волки в лесу охраняют камень — фарм для героя.

## Тайминги
- Короткая: 25 мин до победы по очкам, т.к. флаги близко. Требушет решает к 20-й.
