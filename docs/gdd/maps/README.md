# Карты и провинции — индекс

MAIN — один большой шард, EXTRA — маленькие арены на том же движке.

Файлы:
- `world-shard.md` — шард 4x4 км, 16x16 провинций, столицы, кланы, сезоны
- `provinces.md` — типы провинций, баффы, захват флага 5 мин, очки
- `terrain.md` — высоты, лес, вода, дороги, обзор, штрафы
- `skirmish-plain.md` — арена Равнина 1v1/2v2
- `skirmish-river.md` — арена Речная долина
- `skirmish-pass.md` — арена Горный перевал
- `neutrals.md` — бандиты/волки, лагеря, респаун, награды
- `generation-threejs.md` — генерация heightmap, сетка, данные для кода

База: 1 тайл = 4м. Провинция MAIN = 64x64 тайла = 256x256м. Арена = 384x384 тайла = 1536м.
