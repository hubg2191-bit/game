# Арена Речная долина — skirmish-river

Назначение: 2v2, мосты-чоки, вода-еда.

## Схема
- Река вертикально по центру, 2 моста (север/юг) 8м. Брод в центре (мелко, -40% скорости, кава проходит).
- Базы: 2+2 по углам. У каждой: лес + поле + причал-спот.
- Флаги: Северный мост (камень), Южный мост (дерево), Остров в центре (золото, только бродом).
- Железо: по 1 жиле у баз + 1 на острове.

## Тактика
- Контроль мостов копьями + башней = стена. Обход бродом тяж.кавой с Воеводой-рывком.
- Снос моста: 1000 HP, чинится. Отрезал — выиграл фланг на 2 мин.
- Причалы: +еда без полей, но уязвимы с берега.

## Тайминги
- 0-10: причалы + фермы. 10-25: мосты. 25-40: остров.
