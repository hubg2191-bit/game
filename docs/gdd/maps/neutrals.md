# Нейтралы — neutrals

## Бандиты (лагерь)
- Состав: 8-12 тел (мечи+луки), HP 60, урон 8. Элитный лагерь (золотая/центр): 12 + вожак 200 HP.
- Охрана: золото 300-500 + синий шмот 20% + 200 XP герою.
- Агро 25м, не уходят дальше 40м от лагеря (фарм без риска для базы).
- Респаун: MAIN 5 мин, Схватка 1 раз (убил — нету).

## Волки (стая)
- 5-7 волков, HP 30, урон 5, скорость 7.0 (догоняют рабочих).
- Охрана: еда/лес-спот. Награда: 50 еды + 50 XP.
- Агро 20м, ночью +10м. Боятся факелов/храма (не подходят 10м).

## Тактика фарма
- Старт: 2 ополчения + герой убивают волков без потерь. Бандиты — 3 отряда или герой 3+ ур.
- Следопыт фармит быстрее всех (пассив Добыча +20% XP/золота). Воевода танкует, Наместник ждет обоза.

## Вид Three.js
- Лагерь: костер + палатки + сундук (открывается при зачистке). Волки — серые капсулы + вой-звук ночью.
