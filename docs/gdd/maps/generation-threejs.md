# Генерация карт для кода — generation-threejs

## Данные
- `src/game/data/maps/*.json`: `{id, size_m, heightmap_png, provinces: [{x,y,type,buff}], spawns, mines, camps, bridges}`.
- Heightmap 256x256 px на арены, 1024x1024 на шард (чанки 256). 1 px = 6м арены / 4м шарда.
- Сиды фиксированы для рейтинга (plain_v1, river_v1, pass_v1). Рандома в рейтинге нет. В кастомках — сид + зеркальность.

## Рендер
- Земля: Plane 256x256 сегментов + displace по heightmap в вершинном шейдере. Текстура: трава/камень/песок по высоте+влажности (1 splat-map).
- Лес: 2 InstancedMesh (стволы, кроны) до 3000 шт. на арене. Вода: 1 плоскость с анимацией UV.
- Провинции: оверлей-линии (LineSegments) + флаг-инстансы. Обновляются только при смене владельца.
- Туман: DataTexture 128x128 на арену, 512x512 на шард-чанк. Сервер шлет биты видимости 5 Hz.

## Сетка и поиск пути
- A* на сетке 4м. Стены/вода/горы — блок. Лес — cost x1.5 для кавы. Мост — cost x0.8.
- Формации: отряд идет колонной по пути лидера, разворачивается в линию у цели ( sim-поле `formation` ).

## Для другого чата
- Не генерить красиво — генерить играбельно: ровные базы 200м, проходы минимум 6м, флаги на ровном, жилы не ближе 50м к базе врага.
- Чеклист карты: `загружается <3 сек, 60 fps на 2000 инстансов, все флаги достижимы пехотой, нет запертых спавнов`.
