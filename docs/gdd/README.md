# Thrones & Towns — GDD Index

**Жанр:** Web RTS Total War Lite + Townsmen. **Стек:** Three.js + TypeScript + Node + Colyseus.
**Репозиторий:** `three-game-vite` — деплой на GitHub Pages.

## Концепция одной строкой
Главный режим — **Постоянная Жизнь**: вечный город + вечные герои на шарде, как в Townsmen. Дополнительный режим — **Быстрые бои 15-40 мин** как в Total War: построил, собрал отряды, захватил провинции.

Вариант A (глобал + тактика) + Вариант B (город и война на одной карте) merged: одна тактическая карта Three.js = и город, и поле боя. Стратегический слой — оверлей провинций поверх той же карты.

## Режимы
- **MAIN — Жизнь (persistent):** столица не вайпается внутри сезона (90 дней), офлайн-доход кап 8ч, герои качаются навсегда, кланы держат провинции.
- **EXTRA — Схватка:** 1v1 / 2v2 / FFA до 4 / Кооп vs боты. Длительность 15-40 мин. Награды перетекают в MAIN (золото + XP героям с капом против фарма).
- **Обучение:** 5 миссий.

## Документы
- `01-modes.md` — структура обоих режимов, фазы боя 40 мин, победа/поражение, экономика наград
- `02-races.md` — 3 расы/фракции, уникалки, стартовые бонусы
- `03-resources.md` — 7 ресурсов, формулы еды/морали/апкипа
- `04-buildings.md` — 22 здания, зависимости, уровни, ТТХ
- `05-units.md` — отряды, роли, характеристики, контрудар-треугольник, формации
- `06-heroes.md` — постоянные герои, главный прогресс, скиллы, снаряжение
- `07-tech.md` — архитектура Three.js + сервер, туман, инстансинг, структура кода
- `08-roadmap.md` — MVP 0.1 -> 1.0

## Правило GitHub
Каждый юнит/здание/герой = 1 секция в md + 1 запись в `src/game/data/*.json`. md — для людей, json — для баланса и кода. Деплоится папка `docs/` через gh-pages, данные грузятся игрой напрямую.

## Быстрый старт баланса
Все цифры в GDD — v0.1, тюнятся только через json, без правок кода симуляции (`shared/sim/`).
