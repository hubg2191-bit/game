# Награды и ранги — rewards

## Ранги Схватки (MMR, отдельный от MAIN)
- Бронза/Серебро/Золото/Платина/Алмаз. Калибровка 5 боев. Сезонный софт-ресет: MMR = (MMR*0.6 + 1000*0.4).
- Награда конца сезона по макс.рангу: рамки, флаг, золото (Бронза 200 — Алмаз 3000). Топ-100 — уникалка-питомец у героя (косметика).

## Награды сезона MAIN (клан + личное)
- Топ-1 клан: золотые флаги на сезон + фиолет шмот каждому + 5000з в казну.
- Топ-2/3: серебряные флаги + синь + 2000з.
- Личный топ-10 по вкладу в клане: амулет фиолет. Соло-топ-10: то же минус 30% золота.

## Что остается навсегда (не вайпается)
- Герои ур./перки, шмот, MMR (софт-ресет), косметика, клан-тег, статистика (победы, K/D, флаги).
- Золото до 5000. Остальное конвертится в `жетоны межсезонья` 2:1 — тратятся на косметику/шмот-лотерею.

## Монетизация (только косметика, без pay-to-win)
- Боевой пропуск сезона: флаги, скины зданий, плащи, питомцы. Ускорения стройки — только за дейлики, не за деньги.
- Запрещено продавать: ресурсы, XP, шмот с характеристиками, щиты длиннее 24ч.

## Вид UI
- Вкладка `Сезон`: прогресс-бар очков, таймер фаз, топ-кланов, мои награды-кнопка `Забрать`. Пуш при смене фазы.
