# Квесты и сезоны — индекс

Связывают MAIN (вечное) и Схватку (40 мин): играешь короткие бои — качаешь сезон и героя.

Файлы:
- `onboarding.md` — обучение 5 миссий + 7 дней новичка
- `quests-tavern.md` — доска Таверны, дейлики/викли, клановые
- `season-structure.md` — сезон 90 дней, фазы, очки, вайп
- `events.md` — ивенты: вторжение бандитов, турнир, клановая война
- `rewards.md` — награды, ранги, что остается после вайпа

JSON для кода: `src/game/data/quests.json`, `src/game/data/season.json`.
