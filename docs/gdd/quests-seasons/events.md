# Ивенты — events

## 1. Вторжение бандитов (PvE, каждые выходные 20:00 UTC, 30 мин)
- 3 волны на случайные форпосты/столицы окраины. Волна: 2/3/5 отрядов бандитов + таран.
- Отбей — получи сундук: золото + шмот (фиолет 5% с 3 волны). Проиграл столицу — щит 12ч автоматом.
- Топ-урон по бандитам — +очки сезона 200.

## 2. Турнир Схваток (каждое воскресенье Финала, сетка 8)
- 1v1, BO1 до полуфинала, финал BO3. Карта — Равнина фикс. сид.
- Приз: 1 место — фиолет оружие + 2000з + очки 1000, 2-4 места — синь + очки. Участие — 100з взнос (анти-смурф, идет в призовой).
- Наблюдатель + реплеи автоматом. Смурфы режутся MMR-гейтом (мин. 10 боев).

## 3. Клановая война за центр (по заявке)
- Заявка офицера: 12ч подготовка (8ч в Финале), окно 24ч. Цель — центральные 4 провы.
- Правила окна: щиты в центре не работают, ремонт x2 скорости, потери -50% времени найма (мясорубка).
- Победа: удержи 3 из 4 к концу окна. Награда: +2000 очков + налог с центра 7 дней.

## 4. Ночной караван (дейли-ивент 15 мин, 21:00 UTC)
- Нейтральный обоз едет через середину. Кто остановит (убьет охрану) — забирает 500з + 200ж.
- Маленький, веселый, для онлайна вечером. Виден всем маркером.

## Тех-требования
- Анонс за 1ч + 10 мин (пуш + баннер). Авто-копия чата в `#events`. Лаг-защита: ивент-зоны на отдельных тиках.
