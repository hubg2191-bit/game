# Netcode — индекс

Авторитетный сервер, чистый WebSocket (без движка). Клиент предсказывает, сервер решает.

Файлы:
- `architecture.md` — shared/sim, сервер, БД, тики
- `protocol.md` — команды и снапшоты, форматы
- `sync.md` — предсказание, лаги, реконнект, реплеи, античит
- `rooms.md` — LifeRoom, BattleRoom, матчмейкинг, скейл
- `testing.md` — чек-лист для другого чата, боты, десинк

JSON: `src/game/data/netcode.json` — тики, лимиты, таймауты.
