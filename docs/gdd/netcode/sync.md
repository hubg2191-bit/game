# Синхронизация — sync

## Предсказание (клиент)
- Движение своих — сразу, без ждать сервера. Бой/урон — только от сервера (не предсказывать HP).
- Реконсиляция: сервер-снапшот перезаписывает позицию если delta >2м. Плавно lerp 100мс, не телепорт.

## Лаги
- Задержка <100мс — незаметно. 100-250мс — lerp врагов 200мс. >250мс — иконка `лаг`, приказы в очередь 1 сек.
- Сервер хранит историю 1 сек для хит-проверки требушета/баллисты (попадает по позиции тика выстрела, не текущей).

## Туман и античит
- Сервер не шлет позиции/HP врагов в тумане. Клиент не может запросить. Мапхак бессмысленен.
- Проверки: скорость (телепорт >15м/тик — отклонить), цена (золото уходит только на сервере), APM 10/сек, размер отряда/лимиты 12/3/2.
- Реплей = лог команд + сид. Досмотр читов по реплею.

## Реконнект/реплеи
- Обрыв: клиент держит последний снапшот + шлет `hello {lastSnap}`. Сервер отдает full-snapshot + 5 сек логов. Окно 90 сек в Схватке, бесконечно в MAIN (столица под щитом).
- Реплей пишется всегда, кнопка `Скачать` в финале. Наблюдатель — тот же снапшот с задержкой 30 сек (анти-стримснайп).
