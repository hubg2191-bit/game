# Протокол — protocol

Транспорт: WS, JSON текстом (бинарь позже). Все с `t` тиком клиента и `seq`.

## Клиент -> Сервер (команды, 10/сек макс)
```json
{"cmd":"move","ids":[12,13],"x":400,"z":600,"t":1234,"seq":88}
{"cmd":"attack","ids":[12],"target":45,"t":1235,"seq":89}
{"cmd":"build","b":"barracks","x":100,"z":100,"t":1236,"seq":90}
{"cmd":"recruit","b":7,"unit":"swords","t":1237,"seq":91}
{"cmd":"stance","ids":[12],"stance":"kare","t":1238,"seq":92}
{"cmd":"cast","hero":1,"skill":"rush","t":1239,"seq":93}
{"cmd":"ping","ping":"F1","x":500,"z":500,"t":1240,"seq":94}
```
Валидация: цена, дистанция, туман (нельзя приказать в тумане кроме разведки), КД скилла, лимит отрядов.

## Сервер -> Клиент (дифф-снапшот 10 Hz)
```json
{"snap":1234,"del":[31],"up":[{"id":12,"x":401,"z":601,"hp":1300,"mor":72,"st":"move"}]}
```
Полный снапшот при входе/реконнекте (до 256кб) + `simVersion`.

## Ошибки/кик
`{"err":"no_gold"}` — UI бип, приказ не принят. `{"err":"rate"}` — превысил APM. `{"kick":"desync"}` — версии sim не совпали. `{"ban":300}` — лив из боя.
