# Герои vs Юниты — где что лежит

Герои созданы, не только юниты:
- `docs/gdd/heroes/warlord.md`, `steward.md`, `ranger.md` — 3 героя, у каждого 2 актива + 2 пассива + перки.
- `src/game/data/heroes.json` v0.2 — цифры для кода.
- Юниты отдельно: `docs/gdd/units/*.md` 13 шт. — это отряды, не герои.

## Маппинг Warspear -> наши герои (по форуму классов)
Форум подтверждает структуру: подфорумы Друид / Разящий клинок / Рейнджер / Страж / Варвар / Разбойник / Шаман / Паладин / Жрец / Маг и т.д. У каждого: база + эксперт-навыки + таланты + ребаланс-треды.
Берем у них не классы целиком, а схему прокачки:
- Было: 2 актива + 2 пассива. Становится: 3 базовых + 2 экспертных (открываются с 10 ур.) + 1 талант с 20 ур. — как в Warspear.
- Воевода = Страж/Варвар (танк/чардж), Следопыт = Рейнджер/Искатель (vision/метка), Наместник = Паладин/Шаман (ауры/обоз-хил).
- Добавить 4-го героя-мага (Чернокнижник/Маг): AoE по площади для контри строя — следующим шагом, id `arcanist`.
