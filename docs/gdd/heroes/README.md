# Герои — индекс

Постоянные, качаются в MAIN и Схватке. 1 герой = 1 билд на аккаунт, слоты 2-3 открываются за сезон.

Файлы:
- `warlord.md` — Воевода (фронт/морали)
- `steward.md` — Наместник (экономика/оборона)
- `ranger.md` — Следопыт (разведка/кайт)
- `leveling-gear.md` — прокачка 1-30, перки, шмот 4 слота, ранение/смерть
- `warspear-mapping.md` — маппинг классов Warspear, схема эксперт/талант
- `majesty-warspear.md` — непрямое управление флагами (Majesty 2)
- `paladin.md` — Паладин (танк-хил)
- `druid.md` — Друид (контроль/хил лесом)
- `barbarian.md` — Варвар (пролом/ярость)
- `rogue.md` — Разбойник (стелс/яд)
- `necromancer.md` — Некромант (проклятие/скелеты)
- `mage.md` — Маг (AoE огонь/мороз)

База для всех:
- HP героя: 800 + 60/ур + СИЛ*20. Урон: 25 + СИЛ*3. Скорость: 5.5 м/с (на коне +15% со шмотом). Обзор: 40м (+ ДУХ).
- Мана: 100 + ДУХ*10, реген 2/сек + ДУХ*0.2. Скиллы тратят ману.
- Аура радиус: 20м + ДУХ*0.5м.
- В Схватке герой 1 ур. + докачка до 6 ур. за бой. В MAIN — полный уровень.
- Смерть: Схватка — респаун 30 сек на базе. MAIN — ранение 2ч (в городе работает 50%), за золото мгновенно.
