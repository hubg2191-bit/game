# Баллиста — ballista

Роль: контр-тяжелая, оборона башен, снос баллист врага.

## ТТХ
- Расчет: 1 машина (300 HP) + 3 человека (по 40 HP)
- Урон: 60 болт, пробитие линии (бьет 3 цели навылет)
- Дальность: 70м, мин. 10м, перезаряд 5 сек
- Скорость: 2.5 (толкают), обзор 60м
- Мораль: не бежит, расчет может бежать

## Цена
- 400 дерева + 300 железа + 200 золота, 25 сек, Осадная мастерская
- Upkeep 0.5 еды + 0.3 золота

## Контры
- Сносит тяж.каву за 2 залпа, гвардию за 3.
- Умирает от любой кавы в упор, лекарей нет — чинить только обозом/мастерской.

## Ремонт
- Вне боя чинится 10 HP/сек рядом с мастерской или обозом Наместника.

## Вид Three.js
- Рама-бокс + дуга + болт-бревно. Натяжение-анимация шкалой.

## Баланс
- id `ballista`. Дружественный огонь 50% по своим — микрить.
