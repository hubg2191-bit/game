# Легкая кавалерия — light-cavalry

Роль: разведка, рейды по еде/рабочим, добивание лучников, захват флагов.

## ТТХ
- Размер: 10 всадников
- HP: 60 (600)
- Урон: 9 + бонус чардка x1.8 первые 3 сек
- Броня: легкая
- Скорость: 8.0 (самая быстрая), обзор 55м
- Мораль: 65

## Цена
- 250 еды + 100 золота, 16 сек, Конюшня-1
- Upkeep 1.0 еды + 0.1 золота

## Контры
- Бьет: лучников, лекарей, рабочих,孤立 осадные.
- Умирает: копья x3, ежи, стены/башни, лес -30% скорости.

## Способности
- `Чардж`: авто при разгоне >20м. `Грабеж`: +30% золота при сносе здания (пассив Каганата x2).
- Формации: Клин / Рассыпной.

## Вид Three.js
- Лошадь-бокс + всадник-капсула, 2 инстанса. Пыль-партикл при чардже.

## Баланс
- id `light_cav`. Не давать лук — это нукеры.
