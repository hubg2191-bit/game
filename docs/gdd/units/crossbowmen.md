# Арбалетчики — crossbowmen

Роль: пробитие тяжелой брони, снайперы по гвардии/тяж.каве.

## ТТХ
- Размер: 12
- HP: 50 (600)
- Урон: 14, пробитие 50% брони, перезаряд 4 сек
- Дальность: 40м, минимум 5м (не стреляют в упор)
- Скорость: 3.8, обзор 48м
- Мораль: 60

## Цена
- 250 еды + 200 железа, 18 сек, Стрельбище + Кузница-2
- Upkeep 0.7 еды + 0.1 золота

## Контры
- Бьют: тяжелую пехоту, тяж.каву, баллисту (расчет).
- Боятся: легкой кавы (догоняет пока перезаряд), лучников числом (дешевле).

## Способности
- `Щит-павеза` (стойка): ставится 3 сек, +40% защита от стрел спереди, неподвижны.
- Нет навесной стрельбы через стену.

## Вид Three.js
- Арбалет-бокс + болт-трайсер толще. Звук щелчок-залп.

## Баланс
- id `xbows`, `reload 4.0`. DPS ниже лучников по легкой, выше по тяжелой — так и держать.
