# Гвардия Щитов — guard-nord (уникалка Нордвейн)

Роль: непробиваемая стена, hold точки, прикрытие осадных.

## ТТХ
- Размер: 16
- HP: 100 (1600)
- Урон: 11
- Броня: тяжелая
- Скорость: 3.6 (медленная), обзор 28м
- Мораль: 85

## Цена
- 350 еды + 250 железа, 20 сек, Казармы + Холл Вождей
- Upkeep 1.0 еды + 0.2 золота

## Контры
- Держит всех в лоб, каре держит тяж.каву 1v1.
- Боятся: арбалетов (пробитие), требушета (площадь), обхода с тыла x2.

## Способности
- `Стена щитов`: -50% спереди, -50% скорость, иммунитет к отбросу чардка.
- Формации: Каре / Линия.

## Вид Three.js
- Большой круглый щит, синие плащи. Звук стука щитов.

## Баланс
- Только Нордвейн. id `guard_nord`.
