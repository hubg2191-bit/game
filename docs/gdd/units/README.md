# Юниты — индекс

Отряды, не одиночки. Внутри отряда солдаты — InstancedMesh. HP общее.

Контр-треугольник: Копья > Кава > Лучники > Пехота без щитов > Копья. Арбалеты/осадные бьют тяжелых.

Файлы:
- `militia.md` — Ополчение
- `swordsmen.md` — Мечники
- `spearmen.md` — Копейщики
- `archers.md` — Лучники
- `crossbowmen.md` — Арбалетчики
- `light-cavalry.md` — Легкая кавалерия
- `heavy-cavalry.md` — Тяжелая кавалерия
- `guard-nord.md` — Гвардия Щитов (норд)
- `nukers-kaganat.md` — Нукеры (каганат)
- `halberdiers-league.md` — Алебардисты (лига)
- `ballista.md` — Баллиста
- `trebuchet.md` — Требушет
- `healer.md` — Лекарь

Формулы общие: фланг сбоку x1.5, сзади x2, высота +15% урон, лес скрывает, мораль <30 — бегство 8 сек. См. `../05-units.md`.
