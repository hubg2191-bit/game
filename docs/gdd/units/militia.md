# Ополчение — militia

Роль: мясо, быстрый спам, стройка-защита, гарнир в MAIN для дешевого удержания флага.

## ТТХ v0.1
- Размер отряда: 24
- HP/солдат: 40 (суммарно 960)
- Урон: 6, тип: рубящий легкий
- Броня: легкая (получает x1.3 от лучников, x1.5 от кавы в чардж)
- Скорость: 4.5 м/с
- Дальность: ближний 1.5м, обзор 25м
- Мораль базовая: 50 (низкая, бежит первым)

## Цена / содержание
- Найм: 100 еды + 50 дерева, 8 сек в Казармах-1
- Upkeep: 0.5 еды/сек
- Возврат при роспуске: нет

## Контры
- Бьет: никого уверенно, задавливает числом лучников в ближнем и рабочих.
- Контрится: всем. Кава сносит за 1 чардж, мечники 1 к 1.5.

## Способности / стойки
- Нет активных. Доступны формации Линия / Рассыпной.

## Синергия
- Воевода аура +10 морали делает их терпимыми. Наместник: дешевый гарнизон для налогов.
- Апгрейд в Кузнице-1: +10% HP, цена 150д+100ж.

## Когда брать
- Старт Схватки 0-5 мин: 2 пачки для захвата нейтралов и разведки.
- MAIN: дешевый флаг-держатель в провинции.

## Вид Three.js
- InstancedMesh капсула 1.7м, цвет команды + коричневая тряпка. Щита нет, копье-палка. LOD дальше 60м — точка.
- Звук: крики толпы, звон вил.

## Баланс-заметки для другого чата
- `sim`: `dmg 6, hp 40, morale 50`. Не апать урон, только HP за уровень, иначе убьет смысл мечников.
- JSON id: `militia`.
