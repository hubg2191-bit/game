# Требушет — trebuchet

Роль: снос зданий и стен, контр-баллист, страх площади.

## ТТХ
- Машина 350 HP + 4 расчета
- Урон: 120 площадь радиус 6м, дружественный 50%
- Дальность: 90м, минимальная 25м (слепая зона), перезаряд 8 сек, неточность 3м
- Скорость: 2.0, разбор/сбор 5 сек (не стреляет на ходу)
- Обзор 55м — нужен корректировщик (кава/герой/башня)

## Цена
- 500 дерева + 400 железа + 300 золота, 30 сек, Осадная мастерская-2
- Upkeep 0.5 еды + 0.4 золота

## Контры
- Сносит башню за 3 камня, стену за 2, казарму за 4.
- Бесполезен в ближнем: любая кава/ополчение разбирает. Требует охраны из копий.

## Вид Three.js
- Рама + рычаг-анимация + камень-парабола (предикт-точка для своих). Грохот.

## Баланс
- id `trebuchet`, `aoe true`. Лимит 2 на игрока в Схватке.
