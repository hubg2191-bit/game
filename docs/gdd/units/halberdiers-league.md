# Алебардисты Гильдии — halberdiers-league (уникалка Лига)

Роль: универсал против пехоты и кавы, охрана денег.

## ТТХ
- Размер: 16
- HP: 80 (1280)
- Урон: 12, x2.0 vs кава и vs тяжелая пехота
- Броня: средняя
- Скорость: 4.0, обзор 30м
- Мораль: 70 (75 с героем рядом — компенсирует слабость Лиги)

## Цена
- 350 еды + 300 железа + 150 золота, 20 сек, Казармы + Гильдия
- Upkeep 1.0 еды + 0.3 золота

## Контры
- Бьют: каву, гвардию, мечников.
- Боятся: арбалетов/лучников числом, требушета, цены (дорого спамить).

## Способности
- `Длинный строй`: +2м дальность атаки (бьют через своих). `Каре`.

## Вид Three.js
- Алебарда 2.2м, золотая накидка. Звон.

## Баланс
- Только Лига. id `halberdiers`.
