# Тяжелая кавалерия — heavy-cavalry

Роль: пролом фронта, снос лучников пачкой, страх.

## ТТХ
- Размер: 8
- HP: 140 (1120)
- Урон: 16 + чардж x2.0, топот -10 морали врагу рядом при чардже
- Броня: тяжелая (резист 40% стрел)
- Скорость: 6.5, обзор 40м
- Мораль: 80 (почти не бегут)

## Цена
- 400 еды + 300 железа + 200 золота, 24 сек, Конюшня + Кузница-3
- Upkeep 1.2 еды + 0.3 золота — дорогая

## Контры
- Бьет всех в лоб кроме копий в стойке и стен.
- Контрится: копья/алебардисты x2-3, баллиста в упор, застревание в зданиях.

## Способности
- `Клин`: +30% прорыв, -20% защита с флангов. `Топот`: пассив -морали.

## Вид Three.js
- Крупная лошадь, броня-бокс, копье-ланс. Грохот копыт.

## Баланс
- id `heavy_cav`. Лимит 3 отряда на игрока в Схватке, иначе кава-мета.
