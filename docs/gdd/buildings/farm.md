# Ферма — farm

Роль: базовая еда. Ставится на поле.

## ТТХ
- HP 500/750/1100. Футпринт 4x4м (поле).
- Цена: 80д / 120д+50к / 180д+100к. Рабочие 3. Стройка 12 сек.
- Производство: 3.0 / 4.5 / 6.0 еды/сек. Требует свободное поле 4x4 рядом (не лес/вода/гора).
- С Мельницей в 25м: x1.5.

## Вид Three.js
- Грядки-ряды, рост по таймеру (шейдер роста), крестьянин-инстанс.

## Баланс
- id `farm`. 4 фермы кормят ~30 населения + 3 отряда. Больше — в Пекарню.
