# Казармы — barracks

Роль: найм пехоты.

## ТТХ
- HP 1200/1800. Футпринт 4x4м.
- Цена: 250д+100к, рабочие 4, требует Ратуша-2 + Кузница-1.
- Найм: ополчение, мечники, копейщики, гвардия/алебардисты (с уникалкой).
- Очередь: 3 слота. Скорость найма x0.7 если голод.
- Точка сбора: ставится флагом.

## Вид Three.js
- Плац + стойки с оружием, марш-звук при найме.

## Баланс
- id `barracks`. 2 казармы = двойной найм. Больше 3 — невыгодно по рабочим.
