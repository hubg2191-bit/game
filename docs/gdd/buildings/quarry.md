# Каменоломня — quarry

Роль: камень для Ратуши-2 и стен.

## ТТХ
- HP 600. Футпринт 3x3м.
- Цена: 120д+50е, рабочие 4.
- Производство: 1.5 камня/сек. Бесконечная в v0.1 (упрощение).
- Открывает: Ратуша-2, Стена-камень, Башня.

## Вид Three.js
- Карьер-яма + блоки, пыль.

## Баланс
- id `quarry`. 1-2 шт. достаточно на игру.
