# Пекарня — bakery

Роль: топ-еда лейта, кормит большую армию.

## ТТХ
- HP 600/900. Футпринт 3x3м.
- Цена: 250д+150к, рабочие 3, требует Ратуша-3 + Мельница.
- Производство: 4.0 / 6.0 еды/сек, потребляет 2 зерна/сек с мельницы. Без зерна — встает.
- Бонус: +5 морали городу (запах хлеба).

## Вид Three.js
- Труба-дым, булки на окне. Аромат-партикл (шутка, просто дым).

## Баланс
- id `bakery`. 1-2 шт. на лейт. Цель для рейдов.
