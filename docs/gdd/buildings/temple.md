# Храм — temple

Роль: мораль + хил, найм лекарей.

## ТТХ
- HP 800. Футпринт 3x3м.
- Цена: 200д+100з, рабочие 2, требует Ратуша-2.
- Аура 25м: +10 морали, хил 1%/сек вне боя.
- Найм: лекарь (200з).
- Ап Ур.2: аура 35м, +15 морали.

## Вид Three.js
- Купол/свечи, колокол-звук при хиле, голубь-партикл.

## Баланс
- id `temple`. 1 шт. у фронта решает пуш. Снос первым делом рейдом.
