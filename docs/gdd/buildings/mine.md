# Шахта — mine

Роль: железо для армии. Ставится на точке-жиле (холм).

## ТТХ
- HP 700/1000. Футпринт 3x3м на жиле.
- Цена: 150д+100к, рабочие 5.
- Производство: 1.0 / 1.5 железа/сек.
- Жил на карте: 2-3 на игрока в Схватке (контест), 5-8 в MAIN на шард.

## Вид Three.js
- Вход-штольня + вагонетка, лампа ночью.

## Баланс
- id `mine`. Контроль жил = контроль элиты. Рейдеры бьют сюда первым делом.
