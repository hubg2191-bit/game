# Здания — индекс

Все здания 1-3 ур. Апгрейд x2 цена, +60% HP, +50% эффект. Футпринт — квадрат на сетке 2/3/4м.

Категории:
- Центр: townhall
- Жилье/склад: house, warehouse
- Еда: farm, fishing-dock, mill, bakery
- Пром: sawmill, quarry, mine, forge, market
- Воен: barracks, shooting-range, stable, siege-workshop
- Оборона: wall, tower
- Верa/найм: temple, tavern
- Уникалки: unique-hall-nord, unique-tabun-kaganat, unique-guild-league

Зависимости кратко: Ратуша-1 открывает базу, Ратуша-2 (400д+300к) открывает кузницу/рынок/казармы/храм/дерево-стену, Ратуша-3 (400ж+600з) открывает пекарню/конюшню/осаду/таверну/камень-стену/уникалку.
