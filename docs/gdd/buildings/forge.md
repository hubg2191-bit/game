# Кузница — forge

Роль: открывает железную армию + апгрейды урона/брони.

## ТТХ
- HP 700/1000. Футпринт 3x3м.
- Цена: 200д+150к, рабочие 3, требует Ратуша-2.
- Открывает найм: мечники, копейщики, арбалеты.
- Апгрейды (по 1 на ур. кузницы):
  - Ур.1: +10% HP пехоты (150д+100ж)
  - Ур.2: +10% урон пехоты (250д+200ж)
  - Ур.3: +10% броня vs стрелы (400д+300ж, требует Ратуша-3)

## Вид Three.js
- Горн-свечение, наковальня-звук, искры.

## Баланс
- id `forge`. Без нее — только ополчение/лучники. Снос кузницы = откат врага в дерево.
