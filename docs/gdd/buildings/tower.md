# Башня — tower

Роль: оборона, обзор, корректировка.

## ТТХ
- HP 1500/2200. Футпринт 2x2м.
- Цена: 200д+150к, рабочие 2, требует стена в 10м (не стоит в поле одна).
- Урон: 12/выстрел, дальность 40м, скорострельность 1/1.5 сек. Приоритет — ближайший.
- Обзор: 60м (снимает туман), корректирует требушет (-50% разброс в радиусе).
- Ап Ур.2: +камень 200, +урон 16, +дальность 45м.

## Вид Three.js
- 6м высота, факел ночью, стрела-трассер.

## Баланс
- id `tower`. 3-4 башни закрывают базу. Контрятся баллистой/требушетом вне дальности.
