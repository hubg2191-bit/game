# Рыбацкий причал — fishing-dock

Роль: еда без полей, для карт с водой.

## ТТХ
- HP 500. Футпринт 3x3м у воды (1 клетка в воде).
- Цена: 100д, рабочие 3. Производство 2.5 еды/сек, +1.0 если рядом <2 причалов (не переловить).
- Уязвимость: горит быстро, топят кавой с берега.

## Вид Three.js
- Мостки + лодка, поплавок-анимация, чайки-партикл.

## Баланс
- id `fishing_dock`. Только у воды, макс 4 на базу.
