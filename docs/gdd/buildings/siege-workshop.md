# Осадная мастерская — siege-workshop

Роль: осадные + ремонт.

## ТТХ
- HP 1200. Футпринт 4x4м.
- Цена: 350д+300ж+200з, рабочие 5, требует Ратуша-3 + Кузница-2.
- Найм: баллиста, требушет (вторая — только Ур.2 мастерской).
- Ремонт: осадные в 20м чинятся 10 HP/сек.
- Ап Ур.2: 400д+300ж, +требушет, +20% скорость сборки.

## Вид Three.js
- Козлы + рамы + кран-балка, стук молотков.

## Баланс
- id `siege_workshop`. 1 шт. на игру. Снос = конец осаде.
