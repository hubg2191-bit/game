# Стена — wall

Роль: блок пути, выигрыш времени, ворота.

## ТТХ
- Сегмент 4м. HP: дерево 400/сегмент, камень 900/сегмент.
- Цена: 20д/м дерево (Ратуша-2), 30к/м камень (Ратуша-3). Рабочие 0, строят жители.
- Ворота: +50д/сегмент, пропускают своих, закрываются 3 сек.
- Кава не прыгает, осадные бьют x1.5 по стенам, пехота бьет 50% (ковыряют).

## Механики
- Нельзя обстроить врага полностью (мин. проход 4м к его Ратуше в Схватке — анти-гриф).
- Поджог деревянной: горит.

## Вид Three.js
- Модульные сегменты + зубцы, флаг при захвате? нет — только свои.

## Баланс
- id `wall`. Спам стен жрет камень — 100м камня = 3000 камня.
