# Гильдия — unique-guild-league

Раса: только Лига. Роль: наемники + топ-артиллерия.

## ТТХ
- HP 1500. Футпринт 4x4м.
- Цена: 400д+300з, рабочие 4, требует Ратуша-3 + Рынок.
- Открывает: Алебардисты + Баллиста МК-II (+20% урон, +5м дальность, +100ж к цене).
- Пассив: наемники -20%, рынок +10% золота дополнительно.
- Налог клану: +5% с доходов гильдии в общий склад (MAIN).

## Вид Three.js
- Каменный дом с весами, золото-блеск.

## Баланс
- id `guild_league`. Главная цель для сноса врагом — без нее Лига средняя.
