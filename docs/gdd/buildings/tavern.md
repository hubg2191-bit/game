# Таверна — tavern

Роль: наемники + квесты герою.

## ТТХ
- HP 800. Футпринт 3x3м.
- Цена: 250д+200з, рабочие 2, требует Ратуша-3.
- Найм: любой базовый отряд чужой расы x1.5 цена, upkeep x2. Обновление ассортимента 3 мин.
- Квесты: 3 доски — `убей 20`, `построй 5`, `удержи точку` — награда XP герою + золото. КД 10 мин.

## Вид Three.js
- Кружка-вывеска, шум толпы, свет окон.

## Баланс
- id `tavern`. Лига: -20% на наемников. Остальным — ситуативно против контр-пика.
