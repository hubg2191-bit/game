# Дом — house

Роль: население + налоги. Спам домов = рост, но жрет еду.

## ТТХ
- HP 600/900/1300 по ур. Футпринт 3x3м.
- Цена: 100д / ап 150д+50к / ап 200д+100к. Стройка 15 сек.
- Эффект: +10 населения за ур. (10/20/30), налог +2/+3/+4 з/мин.
- Рабочие: 0 (сам дает слоты).

## Зависимости
- Требует Ратуша-1. Сам требует для Ратуши-2/3 (5/8 домов).

## Механики
- Если еды нет — налоги 0, население бунтует (-морали городу).
- Горит 30 сек при поджоге, тушится жителем за 10 сек.

## Вид Three.js
- Домик с крышей цветом фракции, дым из трубы при заселении, окна светятся.

## Баланс
- id `house`. Кап домов 15. Иначе лаг от инстансов и инфляция населения.
