# Мельница — mill

Роль: буст ферм, зерно для Пекарни.

## ТТХ
- HP 600. Футпринт 3x3м, крылья крутятся.
- Цена: 200д+100к, рабочие 2, требует Ратуша-2.
- Эффект: фермы в 25м x1.5. Дает 2 зерна/сек для Пекарни.
- Сама еды не дает.

## Вид Three.js
- Башня + лопасти-анимация по ветру. Скрип.

## Баланс
- id `mill`. 1 мельница на 3 фермы — золотое правило.
