# Герои vs Юниты в 2.5D — как отличить (бриф)

Рефы из `units/ref/*.jpg` — это рядовые отряды. Герои в том же стиле и палитре, но НЕ один в один.

## Правила отличия (обязательно)
1. Масштаб x1.5 к рядовому того же типа (видно с высоты 40м).
2. Силуэт: уникальный плащ + головной убор + оружие (Воевода — рогатый шлем+знамя, Паладин — щит-солнце, Друид — посох-ветка, Варвар — 2 топора, Разбойник — капюшон+маска, Некромант — череп-посох, Маг — кристалл).
3. Маркер: иконка класса над головой + круг ауры на земле + свечение тира шмота (серый нет, синий слабое, фиолет яркое).
4. Анимация: у героя 4 стейта (idle/walk/cast-Q/cast-E), у рядового 2-3. Каст читается издали.
5. Цвет: база фракции + личный акцент (красный след Варвара, зеленый туман Некроманта, золотой купол Паладина).

## Что сказать другому чату
- Юниты — по `units/ref` 1в1 + LOD-бокс дальше 60м.
- Герои — новые арты по `heroes/*.md`, стиль тот же, силуэт другой. Не реюзать модель мечника для Воеводы.
- Проверка: на скриншоте с высоты героя должно быть видно за 1 сек без подписей.
