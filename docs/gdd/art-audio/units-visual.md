# Юниты визуально — units-visual

## База (все пешие)
- Тело: капсула/бокс 1.7м. Ближние LOD <60м: тело + голова-шар + оружие. Дальше: 1 бокс цвета команды.
- Команда: плащ-плоскость цветом p0-p3 + щит/наплечник фракцией. Герой x1.5 + свечение тира шмота.

## По типам (инстансы)
- militia: коричневая роба, вилы-палка. Без щита — видно издалека что мясо.
- swordsmen: щит-бокс + меч-палка, плащ фракционный.
- spearmen: копье 2.5м цилиндр, в `Ежах` наклон 45° (1 параметр инстанса).
- archers: лук-дуга (тор), колчан-бокс. Залп — трейсер-линия 0.5с.
- xbows: арбалет-бокс + толстый болт-трейсер.
- light_cav: лошадь-бокс 2.2м + всадник, пыль-партикл при чардже.
- heavy_cav: лошадь 2.6м + броня-бокс + ланс 3м. Грохот копыт.
- guard_nord: круглый щит + синий плащ. Стойка — щиты вперед (поворот инстанса).
- nukers: легкая лошадь + лук, стрельба на ходу — трейсер.
- halberdiers: алебарда 2.2м + золотая накидка.
- ballista/trebuchet: рама-боксы, натяжение/рычаг-анимация 1 костью (scale). Камень — парабола + тень-круг.
- healer: белая роба + крест-партикл хила.
- hero: плащ + иконка над головой (Q/E готовность точкой), аура-круг на земле.

## Анимации v0.2 (без скелета)
- Ходьба: bobbing (sin по Y) + наклон. Атака: выпад оружия (scale Z). Смерть: упасть (rotate X 90°) + исчезнуть 3с. Хватит для читаемости.
