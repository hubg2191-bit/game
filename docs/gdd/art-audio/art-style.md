# Арт-стиль — art-style

## Направление
- Лоу-поли RTS: плоские цвета, крупный силуэт, никаких мелких деталей ближе 30м не видно — не делаем.
- Камера 30-80м сверху: важен цвет команды + оружие-силуэт (копье длинное, щит круглый, лук дуга), а не лица.

## Палитры фракций (плащи/крыши/флаги)
- Нордвейн: синий #2f6dff + серый камень + белый мех. Крыши темно-синие.
- Каганат: красный #d23c2e + коричневая кожа + золото. Крыши войлочные бежевые.
- Лига: желтый #e8b400 + черный + белый. Крыши черепичные оранжевые.
- Нейтралы: серый #777 + лохмотья. Бандиты — черный капюшон, волки — серые.

## Цвета команд в бою (поверх фракционных, настройка дальтонизма)
- p0 синий #2f9dff, p1 красный #ff4d4d, p2 желтый #ffd23f, p3 фиолет #b07dff. Свои обводка зеленая #39d353.
- Враг в тумане — не рисуется вообще. Разведка — `?` серым.

## Земля/интерфейс
- Трава 3 тона по высоте, камень серый, песок у воды, снег? нет в v0.2.
- HP-бары: 1 спрайт над отрядом (не над каждым солдатом). Мораль — тонкая синяя полоска под HP при выборе.

## Запреты
- Нет реалистичных текстур 2k, нет скелетной анимации на 2000 тел, нет теней от каждого солдата (1 dir-тень только от зданий/деревьев на High).
