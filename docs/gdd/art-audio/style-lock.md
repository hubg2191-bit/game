# Style Lock v1 — 2.5D изометрия на Three (фикс. 2026-09-23)

Решение: графика = Townsmen + Warspear уклон, механика и остальное без изменений.

## Что зафиксировано
- Камера: изометрия 2.5D, фиксированный угол ~45°, зум ограничен, вращения нет. Total War-свобода камеры выкл.
- Движок: тот же Three.js, без переписывания. 2.5D = лок камеры + орто-режим + теплая палитра.
- Townsmen-черты: теплые мультяшные цвета, читаемые домики с крышами, жители-болванчики, сезоны/дым/флаги.
- Warspear-черты: яркие контурные спрайты-иконки, сочная пиксель-читаемость на мелком масштабе, минимум полутонов.
- Бюджеты без изменений: `palette.json`, `pipeline.md` (<80 draw calls, <300k tris).

## Рефы (подтверждены)
- Townsmen - A Kingdom Rebuilt (Steam 938380, HandyGames, 2019): теги `2D, Isometric, Colorful, Cute, City Builder`. Смотреть шапку/скрины страницы.
- Warspear Online (warspear-online.com/screenshots, Steam 326360): 2D пиксель 16-бит, яркие спрайты, арены 2v2/5v5.
- Northgard: пользователь досмотрит сам.
