# Пайплайн ассетов — pipeline

## Папки
```
src/game/assets/models/ — glb только для героя/осадных (остальное процедурные боксы)
src/game/assets/textures/ — splat 1024, иконки 64px png, флаги svg
src/game/assets/icons/ — 48px svg: стройка/найм/стойки/Q/E
src/game/assets/audio/ — ogg music + sfx
```

## Форматы/бюджеты v0.2
- Модели: glb <200кб, <2k tris (герой 5k макс). Текстуры: 512-1024, atlas 1 шт. для иконок.
- Кадр: draw calls <80, tris <300k, инстансы: солдаты 3-4 кола, деревья 2 кола, здания ~30 кол. Тени: только High + только здания/деревья.
- Экспорт Blender: Y-up, метры, origin у земли, 1 материал на модель. Имя `unit_swordsman_v1.glb`.
