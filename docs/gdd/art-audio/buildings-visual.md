# Здания визуально — buildings-visual

## База
- Футпринты 3x3/4x4м, высота 3-8м. Ур.2 +крыша-пристройка, Ур.3 +башенка/флаг. Стройка: леса-боксы + прогресс % над зданием.
- HP-бар при выборе/уроне. Горит: огонь-партикл + дым. Строится/чинится: стук.

## По типам
- townhall: 4x4, 2-3 этажа, флаг фракции 6м. Ночью окна светятся.
- house: домик + труба-дым при заселении. Лига — черепица, Норд — синяя крыша, Каганат — войлок.
- warehouse: сарай + ящики-стопка по % заполнения.
- farm: грядки-ряды + рост (scale Y по таймеру). mill: лопасти крутятся. bakery: труба-дым гуще.
- sawmill/quarry/mine/forge: пила/яма+блоки/штольня/горн-свечение + искры.
- market/tavern/temple: прилавки-флажки / кружка-вывеска / купол+свечи.
- barracks/shooting/stable/siege: плац+стойки / мишени / стойла+лошади / рамы+кран.
- wall: сегменты 4м + зубцы, ворота-арка. tower: 6м + факел ночью.
- hall_nord: длинный дом + рога + костер. tabun: загон+лошади. guild: весы + золото-блеск.

## Цвета готовности
- Зеленый контур — можно строить, красный — нельзя (склон/вода/чужой флаг). Радиус-аура — кольцо при выборе.
