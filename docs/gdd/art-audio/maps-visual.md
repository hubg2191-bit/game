# Карты визуально — maps-visual

## Свет
- День Схватки: dir-свет 45°, теплый + ambient 0.6. Ночь MAIN: темно-синий + факелы (point-пул 20 шт. у зданий) + окна.
- Туман войны: затемнение 70% + desaturate. Неразведанное — почти черное.

## Земля/вода/лес
- Земля: 1 splat-текстура 1024 (трава/камень/песок по высоте+влажности). Дороги — декаль-полоса +10% скорости видно.
- Вода: 1 плоскость, UV-анимация, отражение выкл (дорого). Брод — светлее + рябь.
- Лес: ствол-цилиндр + крона-икосаэдр, 2 инстанса до 3000 шт. Густой темнее. Рубка — пеньки остаются.
- Горы: серые + снег-шапка выше 6м. Проходы — флажки.

## Эффекты (пулы, не спавн в бою)
- Пыль чардка, кровь-хит (плоский спрайт 0.3с), огонь/дым пожара, хил-крест, аура-круг, метка-ромб, снаряд-трейсер, камень-тень.
- Лимит частиц 500. На Low — только огонь/трейсеры.

## Провинции/флаги
- Граница — пунктир-линия, флаг 6м цветом владельца + иконка баффа. Круг захвата — кольцо-шейдер пульс.
