# Арт и звук — индекс

Цель: читаемость боя с высоты 30-80м, 60 fps на 2000 инстансов. Красиво — потом, читаемо — сейчас.

Файлы:
- `art-style.md` — лоу-поли, палитры фракций, принципы
- `units-visual.md` — как выглядит каждый юнит в Three.js
- `buildings-visual.md` — как выглядит каждое здание
- `maps-visual.md` — свет, земля, вода, эффекты
- `audio.md` — музыка + 40 SFX, приоритеты, WebAudio
- `pipeline.md` — папки, форматы, бюджеты, экспорт

Ассеты: `src/game/assets/{models,textures,icons,audio}/`. Пока — процедурные боксы + цвета, без внешних моделей.
