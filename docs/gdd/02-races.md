# 02 — Расы / Фракции

Всего 3 на релиз. 4-й слот — нейтралы (бандиты/волки для фарма).

## 1. Нордвейн (оборона/пехота)
Лор: северные кланы. Пассив: стены +30% HP, пехота +10% брони зимой/на своей земле.
Стартовый бонус: +100 камень, Казармы строятся 20% быстрее.
Уникальное здание: **Холл Вождей** — +мораль附近 отрядам, открывает Гвардию.
Уникальный юнит: **Гвардия Щитов** — медленная, держит строй, бонус в каре.
Слабость: кавалерия на 15% дороже, нет легкой кавалерии топ-уровня.
Ветка технологий: Оборона -> Мораль -> Осадная стойкость.

## 2. Степной Каганат (рейды/кавалерия)
Лор: кочевники. Пассив: кавалерия +15% скорости, грабеж +30% золота с разоренных зданий.
Стартовый бонус: +1 легкий кавалерист-разведчик, +100 еда.
Уникальное здание: **Конный Табун** — лечит кавалерию в радиусе, открывает Нукеров.
Уникальный юнит: **Нукеры** — тяжелая кавалерия с луками, хит-энд-ран.
Слабость: дома слабее (-15% HP), артиллерия только наемная (дороже 30%).
Ветка: Скорость -> Рейд -> Выживание в поле.

## 3. Вольная Лига (экономика/наемники)
Лор: города-порты. Пассив: +15% золото с рынка, наемники -20% цена, Таверна раньше.
Стартовый бонус: +150 золото, Рынок на 1 ур. сразу.
Уникальное здание: **Гильдия** — открывает наемников всех рас + Баллисту МК-II.
Уникальный юнит: **Алебардисты Гильдии** — универсалы против пехоты и кавалерии, дорогие в upkeep.
Слабость: базовая пехота -10% морали без героя рядом.
Ветка: Торговля -> Наемники -> Артиллерия.

## Балансное правило
Никакая раса не выигрывает 1v1 только пиком. Контртреугольник одинаковый для всех, разница — в цене/скорости/бонусах 10-20%, не в новых правилах.

## Нейтралы
Бандиты (лагерь 8-12 тел, охраняют золото), Волки (быстрые, охраняют еду/лес). Респаун 5 мин в MAIN, 1 раз в Схватке.
