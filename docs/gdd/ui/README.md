# UI/HUD — индекс

HTML поверх Three.js canvas. UI не знает баланса — только читает `sim` + `data/*.json`.

Файлы:
- `hud-main.md` — главный HUD: ресурсы, очередь, выбор, герой, квесты
- `hud-battle.md` — отличия Схватки: счет, таймер, флаги, команды
- `controls.md` — мышь/клава/тач, хоткеи, рамка, формации
- `lobby-menu.md` — меню, лобби, матчмейкинг, профиль, клан, сезон
- `minimap.md` — миникарта, туман, пинги/маркеры
- `components.md` — компоненты для кода `client/ui/*`, токены, цвета команд

Принцип: 2 клика до любого действия. Все строится/нанимается и мышью, и хоткеями.
