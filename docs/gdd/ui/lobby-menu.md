# Меню и лобби — lobby-menu

## Главный экран
- Кнопки: `В город (MAIN)` | `Схватка` | `Герои` | `Клан` | `Сезон` | `Настройки`. Справа — герой-портрет + ранг + золото. Снизу — новости ивентов + кнопка `Играть` (квик-плей по MMR).
- Первый вход новичка — сразу миссия 1, меню после.

## Схватка-лобби
- Режимы плитками: 1v1 / 2v2 / FFA / Кооп. Под каждой — онлайн + время поиска. Кнопка `Найти` <60 сек, отмена без штрафа до 10 сек, потом -MMR за лив.
- Кастомка: создать комнату (пароль, карта, наблюдатели вкл/выкл, боты). Список комнат + `Быстрый вход`.
- Предбой: пики рас (по очереди бан? нет банов в v0.1), готов/не готов, пинг сервера. Ливер в предбое — бан поиска 5 мин.

## Профиль / Герои / Клан / Сезон
- Профиль: MMR-график, K/D, флаги, любимая раса, реплеи (скачать/смотреть).
- Герои: 3 карточки + уровень/XP-бар + кнопки `Кач` (билд перков) + `Шмот` (4 слота drag&drop) + `Лечение` (таймер/золото).
- Клан: ростер, казна, войны-заявки, вклад каждого. Роли: вождь/офицер/боец.
- Сезон: фазы-таймер, очки, топ, награды-кнопка.

## Настройки
- Графика: качество (низк/сред/высок — инстансы/тени/вода), лимит fps. Звук: громкость/отдельно музыка. Камера: скорость/инверсия. Хоткеи-ремап. Язык RU/EN.
