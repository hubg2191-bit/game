# Управление — controls

## Мышь
- ЛКМ: выбрать (клик), рамка (тянуть), добавить в выбор Shift+клик. Двойной клик по юниту — все такие на экране.
- ПКМ: приказ (идти/атаковать/чинить/сесть в стойку через иконку). ПКМ по миникарте — быстрый марш.
- Колесо: зум 15-120м. Средняя кнопка (зажать): вращать. WASD/стрелки + edge-pan двигают камеру. Пробел — к последнему бою. `H` — к Ратуше, `G` — к герою.

## Хоткеи v0.1 (настраиваются)
- `Q/W/E/R/T` — слоты стройки/найма. `Esc` — отмена/закрыть. `Delete` — снести/распустить (с подтверждением).
- Отряды: `Ctrl+1..9` — сохранить группу, `1..9` — выбрать, `A` — атаковать-идти, `S` — стоп, `D` — держать (стойка), `F` — формация-цикл.
- Герой: `Q` рывок/обоз/засада, `E` ульта, `Tab` — цикл героев (если 2-3 слота).
- Пинги: `F1` атака, `F2` оборона, `F3` ресурсы нужны, `F4` ко мне. Alt+клик по земле — быстрый пинг.
- Камера: `+/-` скорость панорамы в настройках.

## Тач (мобилка/планшет, только город MAIN)
- Тап — выбрать, второй тап — приказ. Щипок — зум. Длинный тап — рамка. Схватки на таче — только наблюдение (бой требует мыши).
- Кнопки 64px минимум, стройка свайпом-каруселью.

## Доступность
- Цвета команд: синий/красный/желтый/фиолет + иконки (дальтонизм). Размер шрифта 12-18px настройкой. Субтитры звуков боя опционально.
- APM-лимит сервера 10 приказов/сек — спам режется, в UI счетчик `приказов/сек`.
