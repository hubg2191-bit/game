# HUD Схватки — hud-battle

База как MAIN + сверху центр:

## Верх-центр (полоса счета)
- `1000 очков до победы | 24:36 осталось | Флаги: синий 2 — красный 1`
- Тикающий скор: `+12/сек (2 флага)`. Прогноз `победа через 48с при удержании`.
- Кнопки: `Сдаться` (после 10 мин, нужно 50%+ команды), `Настройки`, `Помощь`.

## Командная панель (справа под миникартой)
- 1v1: герой врага (уровень + жив/респаун 18с) + его апмы? нет апм — только `армия ~8 отрядов`.
- 2v2: 2 союзника: HP героя, золото-кнопка `Отдать 200д`, пинг `Ко мне`.
- FFA: 3 врага цветом + кто кого бьет (стрелки).

## Отличия от MAIN
- Нет доски квестов — только `Флаги` + `Убей вождя бандитов 0/1`.
- Нет офлайн-панелей (казна клана скрыта). Награды боя показываются в конце: `+500з +800XP (2/3 бонуса сегодня)`.
- Реконнект-баннер: `Соединение... 45с | снапшот 12с назад`. Кнопка `Переподключиться`.

## Финал-экран
- Победа/поражение, статистика: K/D, флаги, золото/мин, APM, герой XP. Кнопки `Реплей` `Еще бой` `В город`.
- MVP-отряд подсвечен (`Тяж.кава: 45 убийств`).
