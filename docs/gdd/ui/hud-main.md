# HUD главный — hud-main

## Раскладка 1920x1080 (резина до 1280)
```
[Ресурсы: еда|дерево|камень|железо|золото|население|морали] [Сезон-таймер] [Меню]
[Квест-трекер 3 шт.]                        [Герой: HP/мана Q/E]
                                            [Миникарта 220px]
[Стройка/Найм сетка] [Выбор: отряд HP/морали/стойки] [Чат/Пинги]
```

## 1. Верхняя полоса ресурсов (высота 36px, всегда видна)
- Еда +/-/сек (красная если голод), Дерево, Камень, Железо, Золото +upkeep, Население `занято/всего`, Мораль города 0-100.
- Тултип: источник/сток. Клик по еде — подсветить фермы. Мигает при <5 мин до нуля.
- Справа: `Сезон 42д | Фаза Войны | очки 12.4k` + кнопка меню.

## 2. Левая панель стройки/найма (табы)
- Табы: `Строй` | `Армия` | `Герой` | `Клан`. Сетка иконок 48px + цена + хоткей (Q/W/E...).
- Недоступное — серое + причина (`нужна Кузница-1`). Очередь 3 слота с прогресс-баром + отмена ПКМ (возврат 100% если не начато, 70% если начато).
- Точка сбора: кнопка `Флаг` + клик по земле.

## 3. Нижняя панель выбора
- 1 отряд: портрет, HP-бар, мораль-бар, урон/броня/скорость, кнопки стоек (Линия/Каре/Клин/Рассыпной), кнопка `Отпустить`.
- Мультивыбор: до 12 плиток HP-барами, двойной клик — выбрать всех этого типа на экране.
- Здание: HP, производство/сек, рабочие, кнопки ап/снос, радиус-аура при выборе (кольцо на земле).
- Герой: HP/мана-бары, Q/E с КД-шайбой, уровень + XP-бар, кнопка `Шмот`.

## 4. Правый трекер
- Квесты 3 шт: название + `12/20` + награда. Клик — ведет камеру к цели.
- Ивент-баннер при ивенте + кнопка `Лететь`.
- Чат внизу: вкладки Все/Клан/Команда + быстрые пинги `F1-F4`.

## Состояния
- Голод: еда красная + звонок + баннер `Голод! -30% найма`. Золото 0: предупреждение наемникам `уйдут через 60с`.
- Туман: враг в тумане — только `?` на миникарте при засвете башней.
