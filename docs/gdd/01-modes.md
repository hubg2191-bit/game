# 01 — Режимы: MAIN Жизнь + EXTRA Схватка

## 1. MAIN — Постоянная Жизнь (главный)
Шард: 16x16 провинций на одной Three.js карте 4x4 км. До 60 игроков на шард.
У каждого — столица (несгораемая до 50% HP, дальше щит 24ч). Остальные форпосты — сгораемые.

- Онлайн: строишь как в Townsmen, ставишь приказы героям, собираешь отряды.
- Офлайн: доход капается 8ч, стройка идет медленно (50%), армия ест еду из склада.
- Захват провинций: поставь флаг + удержи 5 мин отрядом 10+. Дает бафф: +15% дерево / +15% железо / +10% мораль и т.д.
- Кланы 5-15 чел: общий склад 10%, совместная оборона, клановые войны за центр карты.
- Сезон 90 дней: вайп провинций и форпостов, столица ужимается до ур.2, герои/косметика/ранг остаются. Это и есть "вечное развитие".

Защита новичков: 72ч щит, нельзя атаковать столицы на 2+ уровня ниже.

## 2. EXTRA — Быстрая Схватка 15-40 мин (A+B)
Та же карта, но маленькая 1.5x1.5 км, все с нуля, все симметрично.

Фазы 40 мин:
- 0-10 мин: Стройка. PvP урон 50%, фокус на еде/дереве.
- 10-30 мин: Экспансия. Открываются центральные провинции с золотом, 2 нейтральных лагеря бандитов (фарм для героя).
- 30-40 мин: Доминация. Точки захвата дают очки каждые 10 сек. Победа: 1000 очков / снос Ратуши / больше очков к таймеру.

Матчмейкинг: MMR отдельный, подбор <60 сек, боты добивают лобби. Реконнект 90 сек по снапшоту. Наблюдатель + реплей.

Награды в MAIN (с капом/день чтобы не фармили):
- Победа: 500 золота + 800 XP герою, поражение: 150 + 300 XP.
- Дейли-кап: 3 боя с полным бонусом, дальше 20%.
