# Баланс v0.2 — индекс

Цель v0.2: Схватка 40 мин заканчивается по очкам/сносу, а не тупиком. MAIN не уходит в инфляцию.

Что поменялось от v0.1:
- Нерф спама ополчения и легкой кавы, ап ядра (мечи/копья).
- Арбалеты быстрее (3.5с), лучники чуть слабее по легкой.
- Тяж.кава: лимит 3 + дороже upkeep, урон 16->15.
- Требушет 120->110 (не сносит базу за 2 залпа), баллиста 60->65.
- Экономика +8-10% к доходу чтобы успеть Т3 к 20-й минуте.
- Герои: рывок КД 40с, обоз 250 еды, засада 12с база.

Файлы:
- `changelog.md` — все цифры diff
- `economy-v02.md` — доходы, апкип, темп по минутам
- `combat-v02.md` — DPS, EHP, TTK-таблица, контрудары
- `pacing.md` — билд-ордеры 1v1/2v2, чекпоинты 10/20/30 мин

JSON обновлены до `"version": "0.2"`: `units.json`, `buildings.json`, `heroes.json`. Id стабильны.
