# 04 — Здания: дерево, зависимости, ТТХ

Уровни 1-3. Апгрейд: +60% HP, +50% эффект, цена ~ x2. Все военные здания требуют рабочих из Населения.

## Дерево зависимостей
```
Ратуша-1 -> Дом / Склад / Ферма / Лесопилка
Ратуша-1 + Казармы? нет: Казармы требуют Кузница-1? упрощенно:
Ратуша-1: Дом, Ферма, Лесопилка, Каменоломня, Склад
Ратуша-2 (камень 300 + дерево 400): Мельница, Кузница, Рынок, Казармы, Стрельбище, Храм, Стена-Дерево
Ратуша-3 (железо 400 + золото 600): Пекарня, Конюшня, Осадная мастерская, Таверна, Гильдия/Холл/Табун (рас.), Стена-Камень, Башня
```
